# 帮助与反馈

当前项目为 Vibe Qwen，使用说明和代码位于[本项目仓库](https://github.com/funkaikai/vibe/tree/fork/macos-baseline)。当前尚未启用 GitHub 问题跟踪或讨论区，也未建立独立社区和在线工单渠道。

## 先查看使用说明

- 导入文件、粘贴分享文案、配置在线文本模型或重试下载：[首页使用说明](../HOMEPAGE.md)。
- 下载、校验、修复或切换语音模型：[Qwen 模型说明](../QWEN.md)。
- 了解当前功能与引擎限制：[完整功能索引](FEATURE_MAP.md)。
- 检查某个平台的实际验证情况：[平台验收记录](../plans/homepage-media-input/platform-validation.md)。
- 了解哪些操作会联网、数据保存位置及密钥存储方式：[隐私与数据说明](PRIVACY.md)。

本地文件可以独立转写；所有链接都需要配置可用的在线文本模型。平台拒绝请求、要求 Cookie 或没有可用视频格式，与本地语音模型的识别失败属于不同处理阶段，记录问题时请注明出错阶段。

## 收集诊断信息

在“设置 > 通用”点击“问题反馈”，应用会整理诊断信息并复制到剪贴板，然后打开本文。**这一步不会自动提交反馈或上传日志。** 可以先将剪贴板内容粘贴到本机文本文件中检查和保存，待整理好后自行提供给项目维护者。

需要进一步排查时，可以在“设置 > 高级”复制日志，或打开日志所在位置。复制失败时，保留应用显示的错误提示；打开日志目录后，也可以手动选择相关片段。诊断信息可能涉及应用和系统版本、模型名称及错误记录，不需要同时提供完整配置文件或音视频原件。

分享前请移除 API Key、账号凭据、配对令牌、个人文件路径和敏感转写内容。签名媒体链接可能含临时授权参数，也应检查后再分享。

## 记录问题时建议包含

1. **运行环境**：macOS 版本、芯片类型、应用版本，以及安装包或本地构建来源。
2. **使用模型**：语音模型名称；涉及链接解析或摘要时，注明文本模型服务和模型名，勿提供 API Key。
3. **复现步骤**：从哪个入口开始、导入文件还是粘贴链接、点击了什么、在哪个阶段失败。
4. **预期与实际结果**：希望发生什么，实际出现的提示、进度停留位置或结果差异。
5. **相关证据**：已脱敏的错误片段或截图；如需媒体样例，优先使用可公开分享的短样例。

不要将本产品的问题、日志或个人数据提交到原项目的反馈渠道。本项目后续建立正式反馈入口后，会在本页和应用中同步更新。

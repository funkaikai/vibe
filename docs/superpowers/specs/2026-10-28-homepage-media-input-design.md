# 首页统一转写输入框设计

日期：2026-10-28
状态：设计草案，整合已确认需求；尚未实现。

## 1. 目标与已确认边界

在当前 Vibe fork 上，将首页的文件、录音、链接切换入口改为以统一输入框为中心的转写入口。外观参考用户提供的 Kimi 首页截图。保留现有侧栏、历史记录、转写结果与播放器。

- 用户可以粘贴音视频链接或完整分享文案，例如包含抖音短链接的分享文本。
- 支持选择或拖入本地音视频文件。
- 输入框左下提供“选择文件”，右下选择语音识别模型并发送。
- 语音识别沿用本地 Qwen3-ASR-1.7B 与现有 Whisper 模型。
- 链接文本理解使用在线大语言模型，通过通用 OpenAI 兼容接口连接，提供 DeepSeek 预设。
- **所有链接必须先经过在线文本模型**，包括直接指向音视频文件的链接。模型未配置、请求失败或响应无效时，停止该链接流程，保留输入并提示；不绕过文本模型下载。
- 本地文件不依赖在线文本模型，可以独立转写。
- 首批目标平台：B站、小红书、YouTube、抖音及音视频文件直链。微博作为可选能力，失败不阻塞本版交付。
- 首版仅处理无需登录即可取得的媒体。不引入账号登录、浏览器 Cookie 或绕过平台限制的功能。
- 新增界面与说明使用简体中文。
- 首页是转写任务入口，不增加持续聊天、摘要生成、系统声音转写或新的录音能力。

## 2. 方案取舍

1. **推荐：统一输入框 + 暂存区 + 任务编排。** 点击发送后依次解析、下载、转写，复用原有结果页。符合参考图，也能明确区分准备输入与开始处理。
2. 保留文件/链接切换页，只调整外观。改动较小，但用户仍需先选择输入类型，无法完成统一输入的目标。
3. 完整对话式 Agent。可支持多轮追问，但会引入会话、工具选择和额外状态；超出本次转写任务入口范围。

## 3. 首页交互

### 空闲状态

中央展示标题“把音视频变成文字”，下方为圆角多行输入框。占位文案：“粘贴视频链接或分享文案，也可以选择音视频文件”。

- 点击“选择文件”或拖入文件后，显示可移除的附件卡片，暂不开始转写。
- 延续现有多文件/文件夹入口；展开文件夹时显示收集状态。
- 输入框内右下显示当前 STT 模型，例如“Qwen3-ASR · 1.7B”，旁边为发送按钮。
- 模型选择复用模型管理信息，仅将可用模型作为直接转写选项；未就绪时提供进入模型管理的入口。
- 默认中文；更多转写参数放在次级入口，不占据输入框主体。
- 无文字且无附件时发送按钮不可用。点击发送或按 Command+Enter 提交，Enter 换行，并避免中文输入法组词期间误提交。
- 同一次提交支持多个链接和多个附件，形成有序任务列表；去重时保留首次出现顺序。首版顺序处理，不增加并发下载或并行模型推理。
- 页面展示简短说明：“链接解析使用在线模型，音视频在本机转写”。

### 提交与处理中

提交后保存原文、附件与模型选择的任务快照，显示每项进度：

`解析输入 → 下载媒体 → 准备音频 → 本地转写 → 完成`

本地文件从准备音频开始。不能计算百分比的阶段只显示状态，不制造估计进度。下载器与转写引擎提供有效进度时再显示百分比。

本次任务固定提交时选择的 STT 模型与转写选项。为复用现有全局模型加载方式，首版在任务处理期间禁用模型切换；失败、取消或完成后恢复。

单项失败不影响其他有效项。混合提交中，文本模型错误只阻止链接项，本地附件仍可处理。错误项提供原因与重试入口，并保留原始输入。重试只重试失败项，避免重复创建已完成结果。

### 完成与失败

- 下载产物校验通过后交给已有转写队列，结果复用现有字幕、播放器、导出与历史记录能力。
- 分享文本与平台媒体标题可用于来源展示；最终名称优先采用下载器确认的媒体标题，不依赖 LLM 编造。
- 文本模型未配置：提供“配置文本模型”入口，并保留原文和附件。
- API 鉴权失败、超时、限流及响应格式错误：显示明确原因，支持修改配置后重试。
- 需要登录、链接过期、平台无法解析、内容无音轨：分别说明原因，并提供“选择本地文件”入口。
- 仅在收到明确登录限制证据时提示需要登录；一般下载失败不能一律归因于登录。
- 取消与退出提醒覆盖解析、下载和转写阶段。已有任务取消能力接入新流程，不增加独立的转写控制面板。

## 4. 在线文本模型

### 配置入口

复用现有 AI 设置连接结构与 OpenAI 兼容客户端，增加“DeepSeek”连接预设；不新增重型 SDK。设置项包含：

- 预设：DeepSeek / 自定义 OpenAI 兼容接口。
- Base URL、API Key、模型名称。
- 测试连接。

DeepSeek 预设填写 `https://api.deepseek.com`，默认候选模型 `deepseek-flash`，另提供 `deepseek-v4-pro`。模型名允许手动修改，避免绑定易变化的服务端名称；模型列表可通过 `/models` 获取，但获取失败不阻断手动配置。

以上地址和名称依据 2026-10-28 查阅的 [DeepSeek 官方接口说明](https://api-docs.deepseek.com/)及[模型列表文档](https://api-docs.deepseek.com/api/list-models/)。这是设计默认值，尚未用用户账号实测。

文本模型配置与首页 STT 选择分别展示。现有 AI 连接也可服务摘要与听写，因此设置页需说明共享连接的用途；选择预设不得自动打开其他 AI 任务。

已有 Claude、Ollama 或自定义连接不自动覆盖。链接解析只使用用户选定的 OpenAI 兼容连接；当前选择不符合时提示进入配置。用户主动切换服务地址时清空 API Key，避免将旧服务凭据发送至新地址；已有自定义连接在未切换预设时保持原值。

API Key 输入采用密码字段，不写入日志或项目结果。现有应用使用本地配置文件保存连接信息；本设计不将其描述为 Keychain 加密存储，也不在本次引入凭据存储迁移。

### 文本模型负责什么

向模型发送本次输入文本与受支持平台清单，要求返回结构化的候选链接、平台与可处理性判断。应用负责校验结构，不直接执行自由文本响应。

- 模型不需要访问视频内容，不接收本地文件路径、音频、视频或转写全文。
- 文本中的指令视为待解析数据，不能覆盖程序规则。
- 候选 URL 必须来自原始输入；不接受模型凭空生成的下载地址。
- 平台判断以本地校验过的域名和受控跳转结果为准。短链接由程序解析；跳转后域名与模型标签冲突时以实际地址为准。
- 仅选择已实现的下载能力，不动态生成或执行 Shell、脚本或下载器代码。
- 所有链接均须获得有效模型解析结果后才进入下载；API 异常不回退为直接下载。

## 5. 下载与模块边界

沿用现有 yt-dlp 与 FFmpeg，按“输入准备 / 在线解析 / 安全地址解析 / 媒体下载 / 本地转写”划分职责。

- 输入准备层管理原文、附件暂存、去重、提交快照和重试。
- 在线解析层复用 OpenAI 兼容客户端，限制输入与输出大小，支持超时与取消，校验结构化响应。
- 地址解析层对输入 URL 及应用主动解析的每次跳转验证 HTTP/HTTPS、域名与目标地址；拒绝凭据 URL、本机/内网地址和非网络协议。平台入口限制在受支持的平台域名，直链单独验证。该检查不等于约束 yt-dlp 内部发出的全部清单/CDN 请求，不宣称下载器已实现网络隔离。媒体地址检查不用于限制用户主动配置的 API Base URL。
- 下载层使用进程参数调用，固定应用管理的输出目录，禁止把外部文本当作命令或输出路径。直链通过媒体类型及探测结果识别，不能只依赖文件扩展名。
- 下载成功必须验证文件存在、非空且含可解码音轨，再进入转写。
- 为历史记录新增可选的公开来源链接字段；旧记录无需迁移，缺少该字段时继续按原有本地路径加载。只保留适合持久化的公开分享链接；不保存带临时签名的媒体地址或签名直链，不通过删除参数制造不可用的替代链接。日志仅记录必要的平台与错误信息。

本次应同时修复直接影响流程的既有行为：当前按空格拆分整段分享文本、下载提交后立即丢失原文、stdout/stderr 读取可能阻塞，以及无输出时取消响应不及时。使用请求或任务标识过滤过期进度，取消后的结果不能进入转写。

## 6. 验证与验收

- 首页：选文件/拖文件暂存、删除附件、输入法与提交快捷键、STT 选择与运行期间锁定、重复提交防护。
- 文本解析：完整抖音分享文案、多链接、URL 尾部中文标点、无链接文本、重复链接、无效 JSON、模型编造地址。
- API：未配置、401/403、429、超时、取消；所有失败均保留输入且不进入链接下载。本地文件无需 API。
- 下载：短链接跳转、协议与地址校验、失败项继续、非空及音轨验证、取消后不转写。
- 转写：真实下载音频通过本地 Qwen 转写并保存；Whisper 切换仍可用，结果记录与实际模型一致。
- 回归：本地多文件转写、历史记录、导出、播放器与窗口顶部拖动。
- 平台必须逐一使用真实的无需登录视频链接验收，记录是否下载成功及是否完成转写。下载器列出平台名仅代表候选能力，不能代替真实验证。
- 没有可验证公开样例或受平台限制的项目，记录实际限制，不宣称完全支持。微博失败可延后；其他目标平台若不能达到验收，需要明确向用户报告阻碍。

# 中文产品说明与导航归属

用户已确认本轮同时处理根 README 和 App 可见导航，沿用当前产品名 Vibe Qwen。

## 目标与范围

- README 全部改为中文产品说明，使用当前 macOS Apple Silicon 交付范围，删除上游宣传、下载、社群、赞助和路线图导航及过期截图。
- App 的项目、模型帮助、更新记录、隐私及反馈均指向当前仓库 `funkaikai/vibe` 的 `fork/macos-baseline` 分支文档。未部署官网、不存在的发行版或未开启的 Issues 不作为可用入口。
- 帮助区提供项目、使用说明、功能总览、问题反馈。移除原产品的赞助与 Discord 按钮。
- 反馈先将诊断复制到剪贴板，再打开本项目反馈说明；URL 不携带日志。原生崩溃反馈也不再跳转原作者的问题页。
- 手机接力仅使用显式配置的 `VIBE_PWA_ORIGIN`，保留运行时优先、编译期后备的行为。没有有效自有网页时不给出配对链接、不启动接力，不删除已有配对数据。

MIT 许可证原版权及授权声明保留。模型、FFmpeg、语音引擎和下载器等实际资源地址不作机械替换。官网配套工程、发布工作流与 GitHub 仓库设置的迁移不纳入本轮；README 不再导航到这些上游页面。应用隐私说明以当前实现为准，不沿用“所有数据绝不离开设备”的旧宣称。

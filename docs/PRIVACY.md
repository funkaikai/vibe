# 隐私与数据说明

更新日期：2026-10-28。

本文说明当前 Vibe Qwen 的数据处理方式，适用于本仓库提供的 macOS 本地开发版本。不同构建的服务配置、用户选择的模型接口及已开启功能，会影响实际网络请求。

## 本地转写

导入的音视频由本机解码，本地 Qwen、Whisper 等语音模型在 Mac 上识别。语音识别流程不将音视频上传到在线语音识别服务；模型准备完成后，可以离线转写本地文件。

“本地转写”并不表示应用的所有功能都不联网。模型下载、媒体下载、在线文本处理、已配置的使用统计，以及打开外部文档等操作会使用网络。

## 在线文本模型

| 功能         | 发送的内容                                 | 接收方                                         |
| ------------ | ------------------------------------------ | ---------------------------------------------- |
| 首页链接解析 | 输入框中的分享文案和候选链接               | 用户配置的在线 OpenAI 兼容接口或 DeepSeek 接口 |
| 摘要         | 转写文本、摘要提示词，以及生成所需的上下文 | 用户选择的文本模型服务                         |
| 转写问答     | 问题、相关转写或摘要、保留的问答上下文     | 用户选择的文本模型服务                         |
| 听写整理     | 听写得到的文本和整理提示词                 | 用户选择的文本模型服务                         |
| 测试连接     | 测试提示词及接口鉴权信息                   | 用户配置的模型接口                             |

链接解析只发送输入文案和候选链接，不上传本地附件音视频，也不把本地附件路径或转写全文作为链接解析输入。所有链接必须完成在线模型解析，本地附件转写无需配置文本 API。

摘要和 AI 听写整理默认关闭。选择连接预设不会自动开启这些功能；手动发起问答时会调用所选服务。Ollama 可指向本机或用户指定的远端服务，实际接收方以配置地址为准。第三方服务如何保留、使用和处理请求数据，应以该服务的说明为准。

## 本地文件与密钥

- 应用配置保存在本机的 `app_config.json`，包含设置、模型接口地址和已填写的 API Key。当前未接入 macOS 钥匙串，API Key 不是以钥匙串加密方式存储。
- 开启保存项目后，转写内容、语言、模型信息、媒体来源，以及已生成的摘要、问答等会写入本地项目记录。应用也会尝试保存媒体副本，便于后续播放。
- 默认项目目录为 `Documents/Vibe Qwen`，可以在“设置 > 转录”中修改。模型存放目录可在模型设置中查看或修改。
- 下载、解码及录音过程可能产生临时文件。项目文件、配置和日志不由应用额外加密；磁盘、备份或同步工具的保护方式由用户的系统环境决定。
- 可以在应用中删除项目和调整保存设置；已手动导出的文件、复制出去的媒体及外部备份需要在相应位置自行管理。关闭保存开关不会自动删除已有项目。

请勿公开分享完整配置文件、API Key、配对凭据，或未检查的日志和截图。

## 使用统计

应用保留使用统计开关，默认开启。只有在构建时同时配置了 `APTABASE_APP_KEY`、`APTABASE_BASE_URL`，且用户未关闭统计时，才会向该构建配置的 Aptabase 服务发送统计事件。没有配置服务的构建不会因开关开启而自动获得上报地址。

统计代码涉及启动、转写状态、耗时、模型或运行环境等技术属性；失败事件可能包含经过长度限制的错误信息。统计还会附带代码版本和本机生成并持久保存的随机安装标识。错误信息可能含有运行时上下文，因此不能把当前实现描述为“任何信息都不会离开设备”。

可在“设置 > 隐私”中关闭使用统计。该开关不控制用户主动触发的在线模型请求、媒体下载或外部网页访问。

## 下载与其他联网功能

模型和辅助工具准备可能访问模型托管站点、代码或工具发布服务。视频链接下载会访问来源平台及媒体分发地址；相关服务可以接收到请求所需的链接、网络地址等信息。第一版链接下载未接入账号登录和浏览器 Cookie 导入。

手机接力需要本产品配置自有手机网页，未配置时不提供配对入口。配置并启用后，手机录音通过点对点或中继网络传给已配对的桌面端，桌面端转写后回传文本；它不是项目云同步。配对设备授权可以撤销，邀请链接和配对凭据不应公开。

当前未配置应用自动更新地址。下载器等辅助工具的更新检查与应用自动更新不同，可能访问各自的发布服务。

## 诊断与反馈

点击“问题反馈”会整理诊断信息并复制到剪贴板，然后打开本项目的[帮助与反馈](FEEDBACK.md)说明。该操作不会把诊断信息自动提交到远端，也不会把日志拼入打开的网页地址。

诊断和日志可能含有应用版本、系统信息、模型名称、文件路径或错误上下文。分享前应自行检查并移除个人信息、凭据及不需要的内容；复制到剪贴板后，也应留意系统剪贴板同步或剪贴板管理工具。
